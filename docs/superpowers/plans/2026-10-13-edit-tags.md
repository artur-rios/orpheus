# Edit a track's tags by hand — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An *Edit tags…* entry in a song's menu opens a form over the file's own tags and front cover, and writes only
what the owner changed, then rescans — issue artur-rios/orpheus#53.

**Architecture:** A new feature folder `lib/features/tag_editor/` (domain → data → application → presentation, like the
others) that reuses the autofill feature's `TagWriter`, `FileTags`, `AutofillField` and `WriteOutcome`. A pure
`tagEdits` function decides what changed; an auto-disposed Riverpod `TagEditController` loads, stamps and saves; an
adaptive `EditTagsDialog` is the form. Two new seams (`FileStamps`, `CoverPicker`) keep `dart:io` and the native file
dialog out of tests.

**Tech Stack:** Flutter, Dart 3, flutter_riverpod 3, file_picker 13.1.0, gen-l10n (en + pt), flutter_test.

**Spec:** `docs/superpowers/specs/2026-10-13-edit-tags-design.md`

## Global Constraints

- Branch: `feature/edit-tags` (already created; the spec is committed on it).
- Only MP3 and FLAC are written (`canWriteTagsTo` in `lib/features/autofill/domain/tag_writer.dart`); nothing in this
  plan widens that.
- A `null` value in a write removes that tag; only fields the owner changed are ever in a write.
- Numbers: track/disc number and total must be whole numbers ≥ 1; year 1 … 9999; blank removes the tag.
- A picked cover must be JPEG (`FF D8 FF`) or PNG (`89 50 4E 47 0D 0A 1A 0A`) by its first bytes.
- `expected` for a write is the stamp taken when the editor read the file, never the catalog entry.
- Every user-visible string is in both `lib/core/l10n/app_en.arb` and `lib/core/l10n/app_pt.arb`, with an `@key`
  `description` (generation fails without one); regenerate with `flutter gen-l10n`. The generated files in
  `lib/core/l10n/generated/` are committed.
- Test names follow the project's `GivenX_WhenY_ThenZ` convention.
- Every task ends green on: `flutter analyze`, `dart format --set-exit-if-changed lib test`, and the task's tests.
- Commit messages: lowercase Conventional Commits, ≤ 50-char subject, ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Code comments match the codebase's voice: doc comments on every public member, explaining *why*.

## Review Focus

1. **A number field typed as `0x10`, `+3`, `-1`, `1.5` or `99999999999999999999`** → shown as invalid and never
   written; `int.tryParse` alone would accept hex and signs (pinned in Task 1).
2. **A field the file holds twice (`Rock; Pop`, `3; 4`) and the owner leaves alone** → not rewritten, and a number field
   shown as `3; 4` must not block *Save* as "invalid" while untouched (pinned in Tasks 1 and 4).
3. **Saving again right after a successful save, before the rescan lands, and saving after *Reload*** → measured
   against the editor's own stamp, so not refused as "changed since read" (pinned in Task 3).
4. **The dialog closed while a write is in flight** → the write finishes and the rescan still starts (pinned in
   Task 3).
5. **A number re-typed with a leading zero (`03` over `3`)** → not a change, so *Save* stays disabled (pinned in
   Task 1).

```dart
import 'dart:typed_data';

import '../../autofill/domain/autofill_field.dart';
import '../../autofill/domain/tag_writer.dart';

/// The fields the form edits as text, in the order it shows them: every field
/// but the cover.
const List<AutofillField> editableTextFields = [
  AutofillField.title,
  AutofillField.artist,
  AutofillField.albumArtist,
  AutofillField.album,
  AutofillField.trackNumber,
  AutofillField.trackTotal,
  AutofillField.discNumber,
  AutofillField.discTotal,
  AutofillField.year,
  AutofillField.genre,
];

/// The fields that hold a number, and are written as one.
const Set<AutofillField> numberFields = {
  AutofillField.trackNumber,
  AutofillField.trackTotal,
  AutofillField.discNumber,
  AutofillField.discTotal,
  AutofillField.year,
};

/// What the owner wants done with the front cover.
sealed class CoverChoice {
  const CoverChoice();
}

/// Leave the cover as the file has it.
final class KeepCover extends CoverChoice {
  /// Creates the choice.
  const KeepCover();
}

/// Take the front cover out of the file.
final class RemoveCover extends CoverChoice {
  /// Creates the choice.
  const RemoveCover();
}

/// Put [bytes] in the file as its front cover.
final class ReplaceCover extends CoverChoice {
  /// Creates the choice.
  const ReplaceCover(this.bytes);

  /// The picture, a JPEG or a PNG.
  final Uint8List bytes;
}

/// What the owner typed or picked, field by field.
class TagForm {
  /// Creates a form.
  const TagForm({this.text = const {}, this.cover = const KeepCover()});

  /// Each text field as typed, untrimmed. A field missing here is no change.
  final Map<AutofillField, String> text;

  /// The cover.
  final CoverChoice cover;
}

/// Why a number field's text cannot be written.
enum NumberProblem {
  /// Not a whole number of one or more.
  notAWholeNumber,

  /// Not a year from 1 to 9999.
  yearOutOfRange,
}

/// [field] of [before] as the form shows it: the text of what the file holds,
/// with several values already joined by `shownAsOne` (`Rock; Pop`), or empty.
String shownText(FileTags before, AutofillField field) =>
    before.values[field]?.toString() ?? '';

/// Digits only: `int.tryParse` alone would take `0x10` and `+3`.
final RegExp _digits = RegExp(r'^[0-9]+$');

/// Why [text] is not a value the number [field] can be written as, or `null`
/// where it is — blank included, which removes the tag.
NumberProblem? numberProblem(AutofillField field, String text) {
  final trimmed = text.trim();
  if (trimmed.isEmpty) return null;

  // `tryParse` answers null for a number too large for an int.
  final value = _digits.hasMatch(trimmed) ? int.tryParse(trimmed) : null;
  if (field == AutofillField.year) {
    return value == null || value < 1 || value > 9999
        ? NumberProblem.yearOutOfRange
        : null;
  }

  return value == null || value < 1 ? NumberProblem.notAWholeNumber : null;
}

/// The number fields of [form] the owner changed into something that cannot
/// be written.
///
/// Only changed ones: a field the file holds twice is shown as `3; 4`, which
/// is not a number, and must not stop a save the owner made elsewhere.
Map<AutofillField, NumberProblem> numberProblems(
  FileTags before,
  TagForm form,
) => {
  for (final field in numberFields)
    if (_changedText(before, form, field) case final text?)
      if (numberProblem(field, text) case final problem?) field: problem,
};

/// What [form] changes in a file holding [before]: each changed field and
/// the value to write, `null` removing the tag. Empty when nothing changed.
///
/// A field [before] cannot write is never in it, nor is a number with a
/// [numberProblem] — callers check [numberProblems] before saving.
Map<AutofillField, Object?> tagEdits(FileTags before, TagForm form) {
  final edits = <AutofillField, Object?>{};

  for (final field in editableTextFields) {
    final text = _changedText(before, form, field);
    if (text == null) continue;

    if (text.isEmpty) {
      edits[field] = null;
    } else if (!numberFields.contains(field)) {
      edits[field] = text;
    } else if (numberProblem(field, text) == null) {
      // `03` over a file's 3 is the same number, and no change.
      final number = int.parse(text);
      if (number != before.values[field]) edits[field] = number;
    }
  }

  if (before.writable.contains(AutofillField.cover)) {
    switch (form.cover) {
      case KeepCover():
        break;
      case RemoveCover():
        if (before.cover != null) edits[AutofillField.cover] = null;
      case ReplaceCover(:final bytes):
        if (!_sameBytes(bytes, before.cover)) {
          edits[AutofillField.cover] = bytes;
        }
    }
  }

  return edits;
}

/// Whether [bytes] are a JPEG or a PNG, by their first bytes — the two
/// pictures every tag format and every reader agree on.
bool isSupportedCover(Uint8List bytes) =>
    _startsWith(bytes, const [0xFF, 0xD8, 0xFF]) ||
    _startsWith(bytes, const [0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A]);

/// [field]'s text in [form], trimmed, where the owner changed it and the file
/// can hold it; `null` otherwise.
String? _changedText(FileTags before, TagForm form, AutofillField field) {
  if (!before.writable.contains(field)) return null;

  final typed = form.text[field];
  if (typed == null) return null;

  final trimmed = typed.trim();
  return trimmed == shownText(before, field).trim() ? null : trimmed;
}

bool _startsWith(Uint8List bytes, List<int> prefix) {
  if (bytes.length < prefix.length) return false;
  for (var i = 0; i < prefix.length; i++) {
    if (bytes[i] != prefix[i]) return false;
  }

  return true;
}

bool _sameBytes(Uint8List left, Uint8List? right) {
  if (right == null || left.length != right.length) return false;
  for (var i = 0; i < left.length; i++) {
    if (left[i] != right[i]) return false;
  }

  return true;
}
```

```dart
/// What a file on disk is now: its size and its modification time.
///
/// What a tag edit measures "changed since it was read" against. Not the
/// catalog's copy of the file, which only a rescan refreshes: a second save
/// made before that rescan lands would be measured against a file that no

abstract interface class FileStamps {
  /// The file at [path] as it is now. Throws where it cannot be read.
  Future<AudioFile> stamp(String path);
}
```

```dart
import 'dart:async';

import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:logging/logging.dart';

import '../../../core/di/providers.dart';
import '../../autofill/domain/autofill_field.dart';
import '../../autofill/domain/tag_writer.dart';
import '../../library/domain/audio_file.dart';
import '../../library/domain/library_access.dart';
import '../../library/domain/music_entry.dart';

/// Where a tag edit is.
enum TagEditStage {
  /// Reading the file's tags.
  loading,

  /// The file cannot be edited; [TagEditState.unwritable] says why.
  unwritable,

  /// The owner is editing. [TagEditState.outcome] or
  /// [TagEditState.refusal] say why the last save did not land, if one did not.
  editing,

  /// Writing.
  saving,

  /// Written.
  saved,
}

/// Why a file cannot be edited.
enum UnwritableReason {
  /// Its format is not one Orpheus writes.
  format,

  /// Its format is, and its tags could not be read, or are of a shape the
  /// writer will not change safely.
  unsafe,
}

/// One tag edit.
class TagEditState {
  /// Creates a state.
  const TagEditState({
    this.stage = TagEditStage.loading,
    this.tags = FileTags.unwritable,
    this.unwritable,
    this.outcome,
    this.refusal,
  });

  /// Where it is.
  final TagEditStage stage;

  /// What the file held when it was read.
  final FileTags tags;

  /// Why it cannot be edited, where it cannot.
  final UnwritableReason? unwritable;

  /// What became of the last save, where it was not written.
  final WriteOutcome? outcome;

  /// Why the last save wrote nothing, where the owner refused access.
  final LibraryAccessDecision? refusal;

  /// A copy at [stage]. [outcome] and [refusal] clear unless passed: each
  /// describes one save.
  TagEditState copyWith({
    TagEditStage? stage,
    WriteOutcome? outcome,
    LibraryAccessDecision? refusal,
  }) => TagEditState(
    stage: stage ?? this.stage,
    tags: tags,
    unwritable: unwritable,
    outcome: outcome,
    refusal: refusal,
  );
}

/// Reads one track's tags, and writes the ones the owner changed.
///
/// Auto-disposed: it lives as long as the dialog watching it. Every await is
/// followed by a check that it still does — except that a write the owner
/// confirmed is finished, and followed by a rescan, whether or not the dialog
/// is still open.
class TagEditController extends Notifier<TagEditState> {
  static final Logger _log = Logger('tag-editor');

  MusicEntry? _entry;
  AudioFile? _read;
  bool _saving = false;

  @override
  TagEditState build() => const TagEditState();

  /// Reads [entry]'s tags to edit.
  Future<void> load(MusicEntry entry) {
    _entry = entry;

    return _inspect(entry);
  }

  /// Reads the same file again, dropping the owner's edits — after another
  /// program changed it.
  Future<void> reload() async {
    final entry = _entry;
    if (entry == null) return;

    await _inspect(entry);
  }

  /// Writes [edits], then rescans.
  ///
  /// One at a time: a second tap while the access prompt is up, or while the
  /// file is being written, would write it twice.
  Future<void> save(Map<AutofillField, Object?> edits) async {
    final entry = _entry;
    final read = _read;
    if (entry == null || read == null || edits.isEmpty || _saving) return;

    _saving = true;
    try {
      await _save(entry.file.path, read, edits);
    } finally {
      _saving = false;
    }
  }

  Future<void> _inspect(MusicEntry entry) async {
    final path = entry.file.path;
    _read = null;
    state = const TagEditState();

    if (!canWriteTagsTo(path)) {
      state = const TagEditState(
        stage: TagEditStage.unwritable,
        unwritable: UnwritableReason.format,
      );
      return;
    }

    try {
      // Stamped first: a file changed between the stamp and the read is
      // refused at the write, never written over.
      final stamp = await ref.read(fileStampsProvider).stamp(path);
      if (!ref.mounted) return;
      final tags = await ref.read(tagWriterProvider).inspect(path);
      if (!ref.mounted) return;

      if (tags.writable.isEmpty) {
        state = const TagEditState(
          stage: TagEditStage.unwritable,
          unwritable: UnwritableReason.unsafe,
        );
        return;
      }

      _read = stamp;
      state = TagEditState(stage: TagEditStage.editing, tags: tags);
    } on Object catch (error) {
      _log.warning('the tags of $path could not be read', error);
      if (!ref.mounted) return;
      state = const TagEditState(
        stage: TagEditStage.unwritable,
        unwritable: UnwritableReason.unsafe,
      );
    }
  }

  Future<void> _save(
    String path,
    AudioFile read,
    Map<AutofillField, Object?> edits,
  ) async {
    // All resolved now: once the dialog closes `ref` can no longer be read,
    // and a write the owner confirmed is still to be finished and followed by
    // a rescan.
    final access = ref.read(libraryAccessControllerProvider.notifier);
    final writer = ref.read(tagWriterProvider);
    final scan = ref.read(scanControllerProvider.notifier);

    state = state.copyWith(stage: TagEditStage.saving);

    final decision = await access.ensureWritable();
    if (!ref.mounted) return;
    if (!decision.isGranted) {
      state = state.copyWith(stage: TagEditStage.editing, refusal: decision);
      return;
    }

    final outcome = await writer.write(path, edits, expected: read);
    if (outcome == WriteOutcome.written) unawaited(scan.rescanSoon());
    if (!ref.mounted) return;

    state = outcome == WriteOutcome.written
        ? state.copyWith(stage: TagEditStage.saved)
        : state.copyWith(stage: TagEditStage.editing, outcome: outcome);
  }
}
```

```dart
import 'dart:typed_data';

import 'package:flutter/material.dart';
```

```dart
/// The form one track's tags are edited in by hand.
///
/// A dialog on a wide window and the whole screen on a phone, where a dialog
/// with ten fields in it would leave the keyboard nowhere to go. Pops `true`
/// once the edit was written, and nothing otherwise.
class EditTagsDialog extends ConsumerStatefulWidget {
  /// Creates the form.
  const EditTagsDialog({required this.entry, super.key});

  /// The track being edited.
  final MusicEntry entry;

  @override
  ConsumerState<EditTagsDialog> createState() => _EditTagsDialogState();
}

class _EditTagsDialogState extends ConsumerState<EditTagsDialog> {
  final Map<AutofillField, TextEditingController> _text = {
    for (final field in editableTextFields) field: TextEditingController(),
  };
  CoverChoice _cover = const KeepCover();
  bool _coverNotImage = false;

  @override
  void initState() {
    super.initState();
    // After the first frame, so the controller is being watched — kept
    // alive — before the file is read.
    WidgetsBinding.instance.addPostFrameCallback((_) {
      if (!mounted) return;
      unawaited(
        ref.read(tagEditControllerProvider.notifier).load(widget.entry),
      );
    });
  }

  @override
  void dispose() {
    for (final controller in _text.values) {
      controller.dispose();
    }
    super.dispose();
  }

  TagForm get _form => TagForm(
    text: {
      for (final MapEntry(:key, :value) in _text.entries) key: value.text,
    },
    cover: _cover,
  );

  /// Puts what the file holds into the form, dropping any edit.
  void _fill(FileTags tags) {
    for (final MapEntry(key: field, value: controller) in _text.entries) {
      controller.text = shownText(tags, field);
    }
    _cover = const KeepCover();
    _coverNotImage = false;
  }

  Future<void> _chooseCover() async {
    final bytes = await ref.read(coverPickerProvider).pickImage();
    if (bytes == null || !mounted) return;

    setState(() {
      _coverNotImage = !isSupportedCover(bytes);
      if (!_coverNotImage) _cover = ReplaceCover(bytes);
    });
  }

  @override
  Widget build(BuildContext context) {
    final l10n = AppLocalizations.of(context);
    final state = ref.watch(tagEditControllerProvider);

    ref.listen(tagEditControllerProvider, (previous, next) {
      // Filled each time the file has just been read — first, and after
      // Reload — and never after a save that did not land, which keeps the
      // owner's edits.
      if (next.stage == TagEditStage.editing &&
          previous?.stage == TagEditStage.loading) {
        setState(() => _fill(next.tags));
      }
      if (next.stage == TagEditStage.saved) Navigator.of(context).pop(true);
    });

    final editing = state.stage == TagEditStage.editing;
    final form = _form;
    final problems = editing
        ? numberProblems(state.tags, form)
        : const <AutofillField, NumberProblem>{};
    final canSave =
        editing &&
        state.outcome != WriteOutcome.changedSinceRead &&
        problems.isEmpty &&
        tagEdits(state.tags, form).isNotEmpty;

    final title = Text(l10n.tagEditTitle);
    final subtitle = Text(
      musicTitleOf(widget.entry, l10n),
      maxLines: 1,
      overflow: TextOverflow.ellipsis,
      style: Theme.of(context).textTheme.bodyMedium,
    );
    final body = switch (state.stage) {
      TagEditStage.loading => const Padding(
        padding: EdgeInsets.all(AppSpacing.md),
        child: Center(child: CircularProgressIndicator()),
      ),
      TagEditStage.unwritable => Text(
        state.unwritable == UnwritableReason.format
            ? l10n.autofillNothingWritable
            : l10n.autofillUnsafeTags,
      ),
      _ => _formView(l10n, state, problems),
    };
    final actions = _actions(l10n, state, canSave);

    if (Breakpoint.from(context) == Breakpoint.phone) {
      return Dialog.fullscreen(
        child: Scaffold(
          appBar: AppBar(leading: const CloseButton(), title: title),
          body: ListView(
            padding: const EdgeInsets.all(AppSpacing.md),
            children: [subtitle, const SizedBox(height: AppSpacing.md), body],
          ),
          bottomNavigationBar: SafeArea(
            child: Padding(
              padding: const EdgeInsets.all(AppSpacing.sm),
              child: OverflowBar(
                alignment: MainAxisAlignment.end,
                spacing: AppSpacing.sm,
                children: actions,
              ),
            ),
          ),
        ),
      );
    }

    return AlertDialog(
      title: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        mainAxisSize: MainAxisSize.min,
        children: [title, subtitle],
      ),
      content: SizedBox(
        width: 480,
        child: SingleChildScrollView(child: body),
      ),
      actions: actions,
    );
  }

  Widget _formView(
    AppLocalizations l10n,
    TagEditState state,
    Map<AutofillField, NumberProblem> problems,
  ) {
    final theme = Theme.of(context);
    final tags = state.tags;
    final busy = state.stage != TagEditStage.editing;
    final notWritable = [
      for (final field in AutofillField.values)
        if (!tags.writable.contains(field)) autofillFieldName(l10n, field),
    ];
    const gap = SizedBox(height: AppSpacing.sm);

    Widget field(AutofillField f) => TextField(
      key: ValueKey(f),
      controller: _text[f],
      enabled: tags.writable.contains(f),
      readOnly: busy,
      keyboardType: numberFields.contains(f)
          ? TextInputType.number
          : TextInputType.text,
      decoration: InputDecoration(
        labelText: autofillFieldName(l10n, f),
        errorText: switch (problems[f]) {
          null => null,
          NumberProblem.notAWholeNumber => l10n.tagEditWholeNumber,
          NumberProblem.yearOutOfRange => l10n.tagEditYearRange,
        },
      ),
      onChanged: (_) => setState(() {}),
    );

    Widget pair(AutofillField left, AutofillField right) => Row(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Expanded(child: field(left)),
        const SizedBox(width: AppSpacing.sm),
        Expanded(child: field(right)),
      ],
    );

    final error = TextStyle(color: theme.colorScheme.error);

    return Column(
      crossAxisAlignment: CrossAxisAlignment.stretch,
      mainAxisSize: MainAxisSize.min,
      children: [
        _coverRow(l10n, tags, busy),

        gap,
        field(AutofillField.artist),
        gap,
        field(AutofillField.albumArtist),
        gap,
        field(AutofillField.album),
        gap,

        gap,
        pair(AutofillField.discNumber, AutofillField.discTotal),

        field(AutofillField.year),
        gap,

                      .read(libraryAccessControllerProvider.notifier)

                child: Text(l10n.autofillOpenSettings),
              ),
            ),
        ],
      ],
    );
  }

  Widget _coverRow(AppLocalizations l10n, FileTags tags, bool busy) {
    final theme = Theme.of(context);
    final writable = tags.writable.contains(AutofillField.cover) && !busy;
    final Uint8List? shown = switch (_cover) {
      KeepCover() => tags.cover,
      RemoveCover() => null,
      ReplaceCover(:final bytes) => bytes,
    };

    return Row(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        SizedBox.square(
          dimension: 96,
          child: shown == null
              ? Icon(
                  Icons.album_outlined,
                  size: 48,
                  semanticLabel: l10n.tagEditNoCover,
                )
              : Image.memory(
                  shown,
                  fit: BoxFit.cover,
                  errorBuilder: (_, _, _) =>
                      const Icon(Icons.broken_image_outlined, size: 48),
                ),
        ),
        const SizedBox(width: AppSpacing.md),
        Expanded(
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Text(
                autofillFieldName(l10n, AutofillField.cover),
                style: theme.textTheme.titleSmall,
              ),
              const SizedBox(height: AppSpacing.xs),
              Wrap(
                spacing: AppSpacing.sm,
                runSpacing: AppSpacing.xs,
                children: [
                  OutlinedButton.icon(
                    icon: const Icon(Icons.image_outlined),
                    label: Text(l10n.tagEditChooseCover),
                    onPressed: writable
                        ? () => unawaited(_chooseCover())
                        : null,
                  ),
                  TextButton(
                    onPressed: writable && shown != null
                        ? () => setState(() {
                            _cover = const RemoveCover();
                            _coverNotImage = false;
                          })
                        : null,
                    child: Text(l10n.tagEditRemoveCover),
                  ),
                ],
              ),
              if (_coverNotImage)
                Text(
                  l10n.tagEditCoverNotImage,
                  style: TextStyle(color: theme.colorScheme.error),
                ),
            ],
          ),
        ),
      ],
    );
  }

  List<Widget> _actions(
    AppLocalizations l10n,
    TagEditState state,
    bool canSave,
  ) {
    final material = MaterialLocalizations.of(context);
    final controller = ref.read(tagEditControllerProvider.notifier);

    if (state.stage == TagEditStage.unwritable) {
      return [
        TextButton(
          onPressed: () => Navigator.of(context).pop(),
          child: Text(material.closeButtonLabel),
        ),
      ];
    }

    final retry =
        state.outcome == WriteOutcome.inUse ||
        state.outcome == WriteOutcome.failed;

    return [
      TextButton(
        onPressed: () => Navigator.of(context).pop(),
        child: Text(material.cancelButtonLabel),
      ),
      if (state.outcome == WriteOutcome.changedSinceRead)
        TextButton(
          onPressed: () => unawaited(controller.reload()),
          child: Text(l10n.tagEditReload),
        ),
      if (state.stage != TagEditStage.loading)
        FilledButton(
          onPressed: canSave
              ? () => unawaited(controller.save(tagEdits(state.tags, _form)))
              : null,
          child: state.stage == TagEditStage.saving
              ? const SizedBox.square(
                  dimension: 16,
                  child: CircularProgressIndicator(strokeWidth: 2),
                )
              : Text(retry ? l10n.autofillTryAgain : l10n.tagEditSave),
        ),
    ];
  }

  String _outcomeMessage(AppLocalizations l10n, WriteOutcome outcome) =>
      switch (outcome) {
```

```
### UC-35: Edit a track's tags by hand

| Field | Value |
| --- | --- |
| **ID** | UC-35 |
| **Name** | Edit a track's tags by hand |
| **Actors** | Owner, Local filesystem, Host platform |
| **Description** | The owner opens a form over one track's own tags and cover, changes what they want, and only what they changed is written — into the file and into the library. |
| **Preconditions** | The library holds the track. |
| **Postconditions** | Exactly the fields the owner changed are in the file's tags, and the library and every screen show them. No audio, file name or place has changed, and no other tag has. Where the owner cancelled, or changed nothing, nothing has been written. |
| **Requirements** | FR-TE-01, FR-TE-02, FR-TE-03, FR-TE-04 |

**Main Flow**

1. The owner picks *Edit tags…* from a track's menu — its button, a right-click, or a long press.
2. The application reads the file's own tags and cover, and notes its size and time (`FR-TE-01`).
3. The form shows title, artist, album artist, album, track number and total, disc number and total, year and genre as
   the file holds them, and its front cover with *Choose image…* and *Remove*.
4. The owner changes what they want. *Save* is offered once something changed and every number is valid (`FR-TE-03`).
5. The owner presses *Save*. The application writes only the changed fields, against the file as it was read
   (`FR-TE-03`).
6. The form closes, the screen says the tags were saved, and the library updates without the owner starting a scan
   (`FR-TE-04`).

| --- | --- | --- |

| AF-03 | The owner changes nothing, or a number is not valid | *Save* stays unavailable, and an invalid number says why. |
| AF-04 | The owner picks a file that is not a JPEG or PNG | The cover is left as it was and the form says why (`FR-TE-01`). |
| AF-05 | The file cannot be written | As UC-34 AF-07, for one file; the owner's edits stay in the form, and a file in use or that failed can be tried again. A file changed by another program since it was read offers *Reload*, which reads it again (`FR-TE-04`). |
```
